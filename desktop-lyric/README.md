# 桌面歌词 (desktop-lyric)

Folia 桌面歌词模组：在桌面上常驻一行歌词，普通字体、可拖动、可锁定、可直接切歌。

## 功能

* **一行歌词**：桌面最上层显示当前播放的一句歌词，上方一行小字是「歌名 — 歌手」。
* **普通字体**：微软雅黑正文样式，不用花哨字体，字号可用 `A-` / `A+` 或快捷键调整。
* **可拖动**：解锁后按住歌词或歌名拖动整条歌词；窗口宽度会按文字实际宽度自动收放，不会留大片透明区挡住桌面点击。
* **锁定**：锁定后窗口变成鼠标穿透，点击/拖拽全部落到下面的程序上，打游戏不误触。
* **切歌**：`⏮` `⏸` `⏭` 直接切上一首、播放暂停、下一首。
* **收起按钮**：解锁状态下点一下歌词可收起/展开那排按钮。
* **自定义颜色**：工具条上的 `🎨` 打开调色板，分别调歌词和作者名的颜色，也可以自己取色。
* **记住状态**：锁定状态、位置、字号、颜色都会存下来，下次启动沿用。

## 快捷键

全局快捷键默认是**关闭**的——它们会抢其他软件里的按键，比如 `Ctrl+Shift+方向键` 在浏览器里是选区扩选。想用的话在「设置 → 模组 → 桌面歌词」打开。

|快捷键|作用|
|-|-|
|`Ctrl+Shift+L`|锁定 / 解锁|
|`Ctrl+Shift+H`|显示 / 隐藏桌面歌词|
|`Ctrl+Shift+Right`|下一首|
|`Ctrl+Shift+Left`|上一首|
|`Ctrl+Shift+Space`|播放 / 暂停|
|`Ctrl+Shift+Up` / `Down`|放大 / 缩小字号|

## 上手：装了之后怎么用

模组装好后不需要任何设置，Folia 播放音乐时桌面会自动出现一行歌词。想调整时的操作都在这一节。

### 第一次使用

1. 打开 Folia，随便播放一首歌。
2. 桌面上出现一行歌词，说明模组已经在工作了。
3. 把鼠标移到歌词条上，会浮出控制条：`⏮` `⏸` `⏭` `A-` `A+` 和锁形按钮、`🎨`、`✕`。
4. 点锁形按钮锁定，歌词条就会对鼠标透明，点哪里都点得穿；再点一次解锁。

### 常用操作

|想做的事|怎么做|
|-|-|
|换下一首 / 上一首|鼠标移到歌词上，点 `⏭` / `⏮`|
|播放 / 暂停|点控制条中间的 `⏸` / `▶`|
|挪动位置|解锁状态下按住歌词条拖动|
|隐藏按钮|解锁状态下点一下歌词条|
|锁定（鼠标穿透）|点控制条上的锁形按钮|
|改颜色|点控制条上的 `🎨`，先选改歌词还是改作者名，再点色块或自己取色|
|改字号|控制条上的 `A-` / `A+`|
|收起歌词条|点 `✕`（只是隐藏，再从「设置 → 模组」或快捷键唤回）|
|完全隐藏歌词|`Ctrl+Shift+H`（需要先在设置里开启快捷键）|

位置、字号、颜色、锁定状态都会自动保存，下次打开 Folia 直接沿用。

### 找不到歌词条？

按顺序排查：

* **Folia 是否在运行**——这个模组只读取 Folia 的播放状态，Folia 关了歌词也会消失。
* **是否点了 `✕` 隐藏**——在「设置 → 模组」里把模组关掉再打开。
* **是否按到 `Ctrl+Shift+H` 隐藏了**——再按一次。
* **是否被拖到屏幕外**——关掉模组再打开，窗口会回到默认位置。
* **是否没给权限**——「设置 → 模组」里检查模组状态，权限没确认的话点一下确认。

### 这个模组不做什么

它只是把 Folia 正在播的歌词搬到桌面上显示，不自己播歌、不改歌单、不联网。Folia 不在播歌时它什么都不显示。

## 安装（新手版）

不用懂任何电脑操作，跟着点就行。

### 方式一：从模组市场装（最简单，推荐）

前提：模组已被 Folia 官方收录。

1. 打开 Folia。
2. 点左下角或侧边的**设置**（齿轮图标）。
3. 找到 **模组** 这一栏，点进去。
4. 点 **模组市场** 按钮，浏览器会打开模组市场网页。
5. 在网页里搜 **桌面歌词**，点安装，按提示确认。
6. 回到 Folia 播放一首歌，桌面上就会出现歌词条。

### 方式二：拖 zip 进 Folia（不用打开任何文件夹）

适用于还没来得及从市场装、或市场里搜不到的情况。

1. 下载 `desktop-lyric-v1.0.0.zip`（不要解压）。
2. 打开 Folia 的 **设置 → 模组**。
3. 用鼠标按住这个 zip 文件，**直接拖进**模组面板中间的区域，松手。
4. 面板会提示正在安装，装完会出现在模组列表里。
5. 如果提示需要确认权限，点确认。

### 方式三：手动放文件夹（适合会一点电脑的）

把 `desktop-lyric/` 整个目录放进：

```
%APPDATA%\\Folia\\mods\\desktop-lyric\\
```

不会找这个路径也没关系：在 Folia 的 **设置 → 模组** 里有个**打开目录**按钮，点它就会直接跳到这个位置，再把文件夹复制进去即可。然后重启 Folia。

### 装完之后该检查什么

进 **设置 → 模组**，在列表里找到「桌面歌词」：

* 显示**已启用**就对了。
* 显示**已签名 / 已验证**说明是通过官方审查的版本。
* 如果显示**未启用**，点一下开关打开。
* 如果提示**权限**，点确认（三个权限的用途见下方「权限说明」）。

然后播放一首歌，桌面就会出现一行歌词。

## 权限说明

|权限|用途|
|-|-|
|`runtime.playback`|读取当前歌曲与歌词进度，用来显示歌词|
|`playback.control`|上一首 / 下一首 / 播放暂停|
|`filesystem.data`|保存位置、字号、颜色、锁定状态|

模组不上传任何数据，不下载执行远程代码，只在模组自己的数据目录（`mods-data/desktop-lyric`）里保存窗口位置、字号、颜色、锁定状态，不改动 Folia 主界面的任何设置和本地数据。

## 技术说明

* `main.cjs`：主进程。创建无边框透明置顶窗口，轮询 Folia 的播放状态，挑出当前行歌词推给渲染层；处理锁定（`setIgnoreMouseEvents`）、拖动（页面自绘，`drag-start/move/end`）、按文字宽度自适应窗口、调色板展开时撑高窗口。
* `client.mjs`：Folia 渲染层入口。只在播放条注册一个锁定按键，不往宿主页面注入任何 DOM。
* `lyric.html` / `preload.cjs`：歌词窗口的界面（含调色板）与 IPC 桥。
